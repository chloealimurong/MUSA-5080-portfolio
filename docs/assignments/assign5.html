The assignment

In class we built a house price model for Philadelphia. Now your team does it for a city you haven’t modeled: Chicago.

The Cook County Assessor’s Office has to value every home in the county, including the vast majority that didn’t sell this year. Assessments drive property tax bills. When they’re wrong in a systematic way, some households pay more than their share. A 2017 Chicago Tribune investigation, “The Tax Divide,” found exactly that in Cook County: lower-value homes were assessed at higher shares of their worth than expensive ones.

Build a model that predicts single-family sale prices in Chicago, 2023–2025, using only the tools from this course. The file contains only features of the house itself. Everything about location is yours to build.

A real test

File What’s in it
chicago_train.csv About 80% of the houses, with sale prices
chicago_test.csv The other 20%, without sale prices. You predict them; we score you.

The test houses were held out by house, not by sale, so a house that sold twice is entirely on one side. Your CV RMSE is your estimate. Your test RMSE is the truth. If they’re far apart, something leaked.

Individual accountability: Q7 on October 30 asks each of you about this model: which features you used and why, your CV and test RMSE, and where the model fails worst. Make sure everyone can explain all of it.

Part 0: Setup (provided)

These helpers are to help you get off the ground.

Code 
check_na <- function(formula, df) {
  vars <- all.vars(formula)
  bad <- vars[sapply(vars, function(v) any(is.na(df[[v]])))]
  if (length(bad) > 0) {
    stop("These variables have NAs: ", paste(bad, collapse = ", "),
         ". Fill them or choose another variable (Rule 1).")
  }
}

# 10-fold CV RMSE, same folds every time
cv_rmse <- function(formula, data) {
  df <- if (inherits(data, "sf")) st_drop_geometry(data) else data
  check_na(formula, df)
  set.seed(5080)
  fit <- train(formula, data = df, method = "lm",
               trControl = trainControl(method = "cv", number = 10))
  fit$results$RMSE
}

# Each house's prediction from the fold where it was held out
cv_pred <- function(formula, data) {
  df <- if (inherits(data, "sf")) st_drop_geometry(data) else data
  check_na(formula, df)
  set.seed(5080)
  fit <- train(formula, data = df, method = "lm",
               trControl = trainControl(method = "cv", number = 10,
                                        savePredictions = "final"))
  fit$pred %>% arrange(rowIndex) %>% pull(pred)
}

# Chicago Data Portal (Socrata) -> sf. `where` is a SoQL filter.
socrata_get <- function(dataset, where, select = NULL, limit = 200000) {
  where <- str_squish(where)
  q <- paste0("$where=", URLencode(where, reserved = TRUE), "&$limit=", limit)
  if (!is.null(select)) q <- paste0(q, "&$select=", URLencode(str_squish(select), reserved = TRUE))
  url <- paste0("https://data.cityofchicago.org/resource/", dataset, ".geojson?", q)
  tmp <- tempfile(fileext = ".geojson")
  resp <- tryCatch(download.file(url, tmp, quiet = TRUE), error = function(e) e)
  if (inherits(resp, "error")) stop("Portal request failed. Open this URL in a browser to see why:\n", url)
  st_read(tmp, quiet = TRUE)
}

Answer: What in your exploration shaped your modeling choices?

Your answer:

Our five cleaning rules removed 39 of 23,200 training sales (see the table above): 30 sales of $5 million or more, 8 homes with more than 4 fireplaces and 1 lot over 3 acres. We checked for $1 transfers and negative ages and found none (the cheapest sale is about $10,000). We kept rows with missing values and filled them instead, and we kept new construction (age 0).

Our first draft also dropped every sale over $1 million. The histogram changed our minds: those 1,892 sales are 8.2% of the training data, not a few outliers, and the test houses are not cleaned, so the model has to price them. Dropping them made CV RMSE look good only because the hardest homes were gone. We now drop only the top 0.1% (over $5 million).

Two other things from the plots shaped the model. The price map shows a clear north/south split, with higher prices on the North Side and near the lake. A model built only on house features cannot see that, so we knew we would need location features. And the age plot is U-shaped: new homes sell highest, prices bottom out for homes 50–100 years old, and rise again for the oldest (historic) homes. So we added age squared.

Answer: What helped most, and what disappointed you? Use your log.

Your answer:

Location helped most. The structure-only baseline (m1) had a CV RMSE of $301,503 and a Moran’s I of 0.455. The house-feature steps (m2–m4: bedrooms, fireplaces, logged bedrooms, age squared) only brought CV RMSE down to $288,721, about $12,800 in total. The three location steps together cut it by almost $70,000. The community-area fixed effect (m7) was the biggest single step, cutting CV RMSE by about $36,700 and Moran’s I from 0.422 to 0.263. Tract income and poverty (m6) came second, cutting CV RMSE by about $24,600; distance to the Loop (m5) added about $8,000. Our final model (m7) has a CV RMSE of $219,363 and a Moran’s I of 0.263.

Three things disappointed us. Logging bedrooms, which we expected to help, changed CV RMSE by less than $600. Distance to the Loop lowered CV RMSE but slightly raised Moran’s I (0.459 to 0.476), so on its own it did not fix the clustering. And even the final model leaves Moran’s I well above zero, so nearby homes are still wrong in the same direction.

The residual maps show what changed. In the baseline map, a large red cluster runs along the North Side lakefront (Lincoln Park, Lake View, North Center): the model under-predicts the city’s most expensive area because it does not know where homes are. In the final map, most of the city is close to zero and that north/south pattern is gone. The large errors that remain are still along the North Side lakefront, but now in both directions, with red and blue points next to each other. The model now knows the neighborhood, but not which homes within it are the top-end ones.

check_na <- function(formula, df) {
  vars <- all.vars(formula)
  bad <- vars[sapply(vars, function(v) any(is.na(df[[v]])))]
  if (length(bad) > 0) {
    stop("These variables have NAs: ", paste(bad, collapse = ", "),
         ". Fill them or choose another variable (Rule 1).")
  }
}

# 10-fold CV RMSE, same folds every time
cv_rmse <- function(formula, data) {
  df <- if (inherits(data, "sf")) st_drop_geometry(data) else data
  check_na(formula, df)
  set.seed(5080)
  fit <- train(formula, data = df, method = "lm",
               trControl = trainControl(method = "cv", number = 10))
  fit$results$RMSE
}

# Each house's prediction from the fold where it was held out
cv_pred <- function(formula, data) {
  df <- if (inherits(data, "sf")) st_drop_geometry(data) else data
  check_na(formula, df)
  set.seed(5080)
  fit <- train(formula, data = df, method = "lm",
               trControl = trainControl(method = "cv", number = 10,
                                        savePredictions = "final"))
  fit$pred %>% arrange(rowIndex) %>% pull(pred)
}

# Chicago Data Portal (Socrata) -> sf. `where` is a SoQL filter.
socrata_get <- function(dataset, where, select = NULL, limit = 200000) {
  where <- str_squish(where)
  q <- paste0("$where=", URLencode(where, reserved = TRUE), "&$limit=", limit)
  if (!is.null(select)) q <- paste0(q, "&$select=", URLencode(str_squish(select), reserved = TRUE))
  url <- paste0("https://data.cityofchicago.org/resource/", dataset, ".geojson?", q)
  tmp <- tempfile(fileext = ".geojson")
  resp <- tryCatch(download.file(url, tmp, quiet = TRUE), error = function(e) e)
  if (inherits(resp, "error")) stop("Portal request failed. Open this URL in a browser to see why:\n", url)
  st_read(tmp, quiet = TRUE)
}
