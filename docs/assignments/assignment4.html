The cross-validation helper

This function runs 10-fold cross-validation with the same seed every time, so every model in my log is tested on the same folds.

Code 
ctrl <- trainControl(method = "cv", number = 10)

cv_rmse <- function(formula, data) {
  df <- if (inherits(data, "sf")) st_drop_geometry(data) else data
  vars <- all.vars(formula)
  bad <- vars[sapply(vars, function(v) any(is.na(df[[v]])))]
  if (length(bad) > 0) {
    stop("These variables have NAs: ", paste(bad, collapse = ", "),
         ". Fill them or choose another variable (Rule 1: don't drop rows).")
  }
  set.seed(5080)
  fit <- train(formula, data = df, method = "lm", trControl = ctrl)
  fit$results$RMSE
}

My outcome is the percent of housing units that are vacant in each Philadelphia tract. There are a couple of reasons agencies may want to predict vacancies. Local law enforcement may want to target specific neighborhoods with higher vacancies for different housing violations (eg. unauthorized occupation). Developers may also want to predict vacancies to determine whether land is up for grabs or if there’s other reasons contributing to vacancies in a neighborhood. These reasons tell us about the housing market and overall state of a neighborhood from a data perspective. From the results above, over 50% of the tracts have low reliability (208). This is to be expected, since vacant units make up a very small portion of overall housing units in a big city. Making that small portion With this in mind, I will continue with the outcome I’ve selected as the information is still relevant to different housing policies for different types of agencies. Even though there may be noise, I will interpret these results more cautiously.

These two layers I found exploring on OpenDataPhilly. Empowerment Zones are specific commercial and/or industrial zones with grants from the government to attract business to the area. The second layer, Redevelopment Certified Areas are areas determined by the Philadelphia Planning Commission as blighted and eligible for urban renewal. Whereas the ACS variables tell us more about the people living on the land (tracts).

4B: Density: don’t skip this

Raw counts mostly measure tract size. A big tract has more of everything. Normalize by area, by population, or by housing units, depending on what makes sense for the thing you’re counting.

Code 
tracts <- tracts %>%

# Merge overlapping polygons so nothing is double-counted
ez  <- layer1 %>% st_make_valid() %>% st_union()
rda <- layer2 %>% st_make_valid() %>% st_union()

# % of each tract's area covered by a polygon layer
pct_in <- function(poly) {
  covered <- st_intersection(select(tracts, GEOID), poly) %>%
    mutate(a = as.numeric(st_area(.))) %>%
    st_drop_geometry() %>%
    group_by(GEOID) %>%
    summarize(a = sum(a))

  a <- covered$a[match(tracts$GEOID, covered$GEOID)]
  replace_na(a, 0) / as.numeric(st_area(tracts)) * 100
}

# Build the three features
tracts <- tracts %>%
  mutate(
    pct_ez = pct_in(ez),
    pct_rda = pct_in(rda),
    dist_rda_mi = as.numeric(st_distance(., rda)) / 5280
  )

# Add a row to the model log
log_model <- function(name, added, formula, notes = "___") {
  model_log <<- model_log %>%
    add_row(model = name, added = added,
            cv_rmse = cv_rmse(formula, tracts), notes = notes)
}

Part 5: Transforming features

5A: Logs, for skewed predictors

Many urban variables are skewed: a few tracts have huge values, and most have small ones. Income, density, and counts are typical. A log compresses the long tail, so a model can use the difference between 1 and 10 as well as the difference between 100 and 1,000.

Part 7: Reflection

  1. What helped, and what didn’t? The portion of a tract inside a Redevelopment Area helped most, lowering CV RMSE from 5.56 to 5.21 percentage points of vacancy. These areas are places the city has already flagged for disinvestment, which my ACS variables, which only describe who lives in a tract, couldn’t see. The squared bachelor’s term disappointed me most. It was significant on its own, but CV RMSE rose from 5.156 to 5.172, probably because the Redevelopment Area variables already captured the signal it was picking up. Logging poverty and grouping tracts by Redevelopment Area coverage each moved CV RMSE by less than 0.02, so neither earned a place in the final model.

  2. Read one coefficient twice. For pct_rda, the β̂ reading is that, holding the other predictors constant, each additional percentage point of a tract’s area inside a Redevelopment Area goes with about [0.04] percentage points higher vacancy. The ŷ reading is that a tract with half its area in a Redevelopment Area is predicted to have a vacancy rate about [2] points higher than an otherwise identical tract with none.

  3. What’s still missing? I’d want to measure housing type, such as the share of units in large buildings or built recently, because vacancy in those places can reflect turnover or lease-up rather than disinvestment. Building permits and zoning layers on OpenDataPhilly could supply this. There’s one layer called “Certified for Rental Suitability” on OpenDataPhilly, I could try to run an analysis and see the relationship with the proximity to places with rental suitability.

  4. How much of the remaining error might be uncertainty or statistical noise? Noise explains only part of it. The largest misses, 15 to 20 points, occur in tracts with CVs of roughly 10 to 25%, where the estimate is fairly precise, so those are real model failures. Misses are smallest where CV is around 35 to 60%, and rise only modestly above 90%, where the estimates are least reliable. Since CV falls as the vacancy rate rises, those large misses are probably high-vacancy tracts the model underpredicts. Still, with about half my tracts above 40% CV, some of the 5-point CV RMSE can’t be reduced by any model.

### The cross-validation helper

This function runs 10-fold cross-validation with the same seed every time, so every model in my log is tested on the same folds.

```{r}
#| label: cv-helper
ctrl <- trainControl(method = "cv", number = 10)

cv_rmse <- function(formula, data) {
  df <- if (inherits(data, "sf")) st_drop_geometry(data) else data
  vars <- all.vars(formula)
  bad <- vars[sapply(vars, function(v) any(is.na(df[[v]])))]
  if (length(bad) > 0) {
    stop("These variables have NAs: ", paste(bad, collapse = ", "),
         ". Fill them or choose another variable (Rule 1: don't drop rows).")
  }
  set.seed(5080)
  fit <- train(formula, data = df, method = "lm", trControl = ctrl)
  fit$results$RMSE
}
```

### 5A: Logs, for skewed predictors

Many urban variables are skewed: a few tracts have huge values, and most have small ones. Income, density, and counts are typical. A log compresses the long tail, so a model can use the difference between 1 and 10 as well as the difference between 100 and 1,000.


### 5B: Squared terms, for curves

If my scatterplot bends (rising and then flattening, or falling and then rising), a squared term lets the line curve. Write it with `I()`, which tells R to do the arithmetic rather than read `^` as formula syntax.

```{r}
#| label: squared-example
m_sq <- lm(y ~ dist_ch_mi + I(dist_ch_mi^2), data = tracts)
summary(m_sq)
```

## Part 7: Reflection

1. **What helped, and what didn't?** The portion of a tract inside a Redevelopment Area helped most, lowering CV RMSE from 5.56 to 5.21 percentage points of vacancy. These areas are places the city has already flagged for disinvestment, which my ACS variables, which only describe who lives in a tract, couldn’t see. The squared bachelor’s term disappointed me most. It was significant on its own, but CV RMSE rose from 5.156 to 5.172, probably because the Redevelopment Area variables already captured the signal it was picking up. Logging poverty and grouping tracts by Redevelopment Area coverage each moved CV RMSE by less than 0.02, so neither earned a place in the final model.

2. **Read one coefficient twice.** For pct_rda, the β̂ reading is that, holding the other predictors constant, each additional percentage point of a tract’s area inside a Redevelopment Area goes with about [0.04] percentage points higher vacancy. The ŷ reading is that a tract with half its area in a Redevelopment Area is predicted to have a vacancy rate about [2] points higher than an otherwise identical tract with none.

3. **What's still missing?** I’d want to measure housing type, such as the share of units in large buildings or built recently, because vacancy in those places can reflect turnover or lease-up rather than disinvestment. Building permits and zoning layers on OpenDataPhilly could supply this. There's one layer called "Certified for Rental Suitability" on OpenDataPhilly, I could try to run an analysis and see the relationship with the proximity to places with rental suitability. 

4. **How much of the remaining error might be uncertainty or statistical noise?** Noise explains only part of it. The largest misses, 15 to 20 points, occur in tracts with CVs of roughly 10 to 25%, where the estimate is fairly precise, so those are real model failures. Misses are smallest where CV is around 35 to 60%, and rise only modestly above 90%, where the estimates are least reliable. Since CV falls as the vacancy rate rises, those large misses are probably high-vacancy tracts the model underpredicts. Still, with about half my tracts above 40% CV, some of the 5-point CV RMSE can’t be reduced by any model.
